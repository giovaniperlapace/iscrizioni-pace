# Link temporaneo di approvazione

Su correzione esplicita dell’utente rimossi tabella link, gestione Admin,
creazione e revoca. Un solo token casuale viene verificato prima delle letture,
con digest e scadenza di 3 giorni nella variabile server HOME_APPROVAL_LINK.
Il link precedente non è valido nella nuova implementazione.

Resta solo la proiezione del programma via RPC service-only, per mostrare
bozze e disponibilità aggiornate senza esporre persone. Home pubblica internal
invariata, nessun login per l’anteprima, iscrizioni disabilitate. No-store,
no-referrer e noindex conservati. Migration storiche conservate; migration
additive 20261010122000 e 20261010123000 sostituiscono la lettura e rimuovono
la tabella e la vecchia RPC. Backup precedente sul server conservato.
